# CodeMaster System 数据库字典

## 1. 文档信息
- 项目名称：CodeMaster System
- 文档版本：v1.0
- 生成时间：2026-05-08 15:09:47 CST
- 生成依据：entry/models.py、entry/migrations/、模型 Meta、字段 choices、外键关系、db_table。
- 注意事项：本文不包含真实业务数据，不读取生产数据库，不包含 .env 内容。

## 2. 数据库总览
- 默认数据库：PostgreSQL，配置项来自环境变量/.env，但本文不读取或输出 .env 内容。
- 核心 app：entry。大多数表遵循 Django 默认命名 `entry_<model>`。
- `Question` 模型显式设置 `db_table = "questions"`。
- 根据 settings.py，当前 `INSTALLED_APPS` 仅包含 `django.contrib.staticfiles` 和 `entry.apps.EntryConfig`，未启用 Django 原生 auth/session/admin 表。

## 3. 核心实体分组
1. Homework Stats：HomeworkCompletionStat, HomeworkCompletionStatMissingAssignment
2. 作业导入：HomeworkImportJob
3. 作业布置：HomeworkAssignment
4. 作业提交：HomeworkSummary, HomeworkSubmission
5. 内容开放权限：StudentContentAccess
6. 在线题目：HomeworkQuestion
7. 奖励记录：RewardRecord
8. 学生主档：Student
9. 教师-学生负责关系：TeacherStudentAssignment
10. 教师评价：TeacherEvaluation
11. 知识点 / CourseContent 管理：CourseContent
12. 课时流水：LessonHourLedger
13. 课程结构：Course, CourseCategory, CourseLevel
14. 账号与角色：PortalUser
15. 逐题答案：HomeworkSubmissionAnswer
16. 通用题库：Question

## 6. 实体关系说明
1. PortalUser -> Student：Student.user 一对一绑定学生账号；Student.parent_user/teacher_user 分别指向家长和教师账号。
2. PortalUser(teacher) -> TeacherStudentAssignment -> Student：教师通过 assignment 获得课程/级别维度的负责关系。
3. Course -> CourseCategory -> CourseLevel -> CourseContent：课程结构主链路。
4. Student -> StudentContentAccess -> CourseContent：学生内容开放权限链路。
5. HomeworkAssignment -> HomeworkImportJob：单个作业可有导入任务；批量作业也可引用公共题源。
6. HomeworkAssignment -> HomeworkQuestion：正式在线题目归属作业；若无直接题目，可从 source_import_job 取题。
7. HomeworkAssignment -> HomeworkSubmission：一个作业支持多次提交。
8. HomeworkSubmission -> HomeworkSubmissionAnswer：一次提交包含逐题答案。
9. HomeworkSubmissionAnswer -> HomeworkQuestion：逐题答案关联作业题目，并保存正确答案/解析快照。
10. TeacherEvaluation / RewardRecord / LessonHourLedger 与 Student / Teacher：记录教学评价、奖励和课时流水。

## 7. 作业主链路专项说明
核心链路为 `HomeworkAssignment -> HomeworkImportJob -> HomeworkQuestion -> HomeworkSubmission -> HomeworkSubmissionAnswer`。教师先创建 HomeworkAssignment；上传题源后形成 HomeworkImportJob；解析并确认候选题后写入 HomeworkQuestion；学生每次在线提交创建 HomeworkSubmission；每道题的选择、正误、正确答案快照和解析快照写入 HomeworkSubmissionAnswer。Homework Stats 页面根据 Assignment、Submission 和 Answer 聚合完成率、正确率、知识点表现和下钻详情。

## 8. 内容权限链路专项说明
课程结构由 Course、CourseCategory、CourseLevel、CourseContent 组织。教师负责范围由 TeacherStudentAssignment 定义，学生是否可见具体内容由 StudentContentAccess 控制。`entry/content_visibility.py` 提供 C1-C4 权限级别、GESP/CSP 阶段映射和可见性判断。作业布置时 `ensure_homework_content_access` 会同步开放对应内容。

## 9. 数据库设计风险与扩展建议
- 核心表：PortalUser、Student、TeacherStudentAssignment、Course/CourseCategory/CourseLevel/CourseContent、StudentContentAccess、HomeworkAssignment、HomeworkImportJob、HomeworkQuestion、HomeworkSubmission、HomeworkSubmissionAnswer。
- 可能需要关注索引：HomeworkAssignment 的 teacher/student/due_date/status，HomeworkSubmission 的 assignment/student/status，CourseContent 的 level/permission_code/is_active，TeacherStudentAssignment 的 teacher/student/course/level_code。
- 不应随意删除：账号、学生、课程结构、内容权限、作业、提交、逐题答案、课时流水；历史链路依赖这些表。
- 适合增加状态字段：Question、TeacherEvaluation、RewardRecord、LessonHourLedger 可考虑 is_active/审核状态。
- 适合增加审计日志：内容权限变更、课时流水、学生导入、作业题目覆盖、评价修改。
- 历史兼容风险：Question.payload、HomeworkImportJob.candidates_json、HomeworkQuestion.options_json/source_snapshot_json 可能存在旧结构。
