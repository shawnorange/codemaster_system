# GESP 三级知识对照表

> 适用场景：题库标签、课后总结、错题归因、阶段测评分析。  
> 整理原则：按照 GESP 三级思维导图知识范围，结合近年 C++ 三级真题常见落地题型进行拆分。  
> 核心变化：三级开始从“会写循环和判断”进入“理解计算机表示、位运算、数组、字符串函数、枚举与模拟”的阶段。

## 一、知识点总表

| 一级目录 | 二级目录 | 三级训练点 / 典型考法 |
|---|---|---|
| 数据编码 | 机器数与真值 | 区分计算机内部存储形式和数学真实值；符号位含义；机器数不等于真值 |
| 数据编码 | 原码 | 符号位 + 数值位；正数原码等于自身；负数原码最高位为 1；8 位原码范围 `-127 ~ 127` |
| 数据编码 | 原码中的 0 | 原码存在 `+0` 和 `-0` 两种表示；选择题常考“0 有几种表示” |
| 数据编码 | 反码 | 正数反码等于原码；负数反码为符号位不变，数值位按位取反 |
| 数据编码 | 反码中的 0 | 反码也存在 `+0` 和 `-0` 两种表示 |
| 数据编码 | 补码 | 正数补码等于原码；负数补码为反码加 1；补码用于简化整数加减法 |
| 数据编码 | 补码表示范围 | n 位补码范围：`-2^(n-1) ~ 2^(n-1)-1`；8 位补码范围 `-128 ~ 127` |
| 数据编码 | 负数补码转真值 | 先判断最高位；最高位为 1 表示负数；取反加 1 得绝对值，再加负号 |
| 数据编码 | 真值转补码 | 正数直接写二进制补足位数；负数先写绝对值，再取反加 1 |
| 数据编码 | 补码加减法 | 用补码直接相加；最高位溢出可能舍弃；根据符号位和进位判断溢出 |
| 数据编码 | 无符号整数 | `unsigned` 没有负数；n 位无符号范围 `0 ~ 2^n-1`；负数转 unsigned 的输出陷阱 |
| 数据编码 | 字节与位 | 1 Byte = 8 bit；根据字节数计算可表示范围，如 2 字节 unsigned 范围 |
| 数据编码 | ASCII 编码 | `'0'` 是 48，`'A'` 是 65；字符转整数、大小写字符间隔、字符参与运算 |
| 数据编码 | UTF-8 基础 | 1/2/3/4 字节编码规则；判断合法字节序列；中文在 `string` 中通常占多个字节 |
| 数据编码 | Base64 基础 | 每 3 字节编码成 4 字节；不足 3 的倍数用 `=` 填充；常考输出长度计算 |
| 进制转换 | 二进制整数转十进制 | 按权展开：从右往左依次是 `2^0、2^1、2^2...` |
| 进制转换 | 八进制整数转十进制 | 按权展开：每一位权值为 `8^k`；八进制每位最大数字是 7 |
| 进制转换 | 十六进制整数转十进制 | `A~F` 对应 `10~15`；每一位权值为 `16^k` |
| 进制转换 | 十进制整数转二进制 | 除 2 取余，倒序输出；注意 `0` 的特殊处理 |
| 进制转换 | 十进制整数转八进制 | 除 8 取余，倒序输出；常配合数组保存余数 |
| 进制转换 | 十进制整数转十六进制 | 除 16 取余；余数 `10~15` 转为 `A~F` |
| 进制转换 | 二进制转八进制 | 从小数点向两边每 3 位分组，不足补 0 |
| 进制转换 | 二进制转十六进制 | 从小数点向两边每 4 位分组，不足补 0 |
| 进制转换 | 八进制转二进制 | 每 1 位八进制转成 3 位二进制 |
| 进制转换 | 十六进制转二进制 | 每 1 位十六进制转成 4 位二进制 |
| 进制转换 | 二进制小数转十进制 | 小数点后第一位是 `1/2`，第二位是 `1/4`，第三位是 `1/8` |
| 进制转换 | 十进制小数转二进制 | 小数部分不断乘 2，取整数部分；可能出现无限循环小数 |
| 进制转换 | 八进制小数转十进制 | 小数点后第一位权值为 `1/8`，第二位为 `1/64` |
| 进制转换 | 十六进制小数转十进制 | 小数点后第一位权值为 `1/16`，第二位为 `1/256` |
| 进制转换 | C++ 进制字面量 | `0x` 表示十六进制；部分环境支持 `0b` 二进制；前导 `0` 可能表示八进制 |
| 进制转换 | C++ 输出进制 | `cout << oct` 输出八进制；`cout << hex` 输出十六进制；`cout << dec` 回到十进制 |
| 进制转换 | 小数精度陷阱 | `double` 不能精确表示很多十进制小数；`0.9` 和 `1.0-0.1` 比较可能出错 |
| 位运算 | 按位与 `&` | 两位都为 1 才得 1；常用于判断奇偶、保留低位、清除某些位 |
| 位运算 | 按位或 | 有 1 就得 1；常用于把某些位设置为 1 |
| 位运算 | 按位异或 `^` | 相同为 0，不同为 1；常用于交换变量、翻转某一位、判断相等 |
| 位运算 | 按位取反 `~` | 每一位 0/1 互换；补码下常见规律：`~x == -x - 1` |
| 位运算 | 左移 `<<` | 非负整数左移 k 位，相当于乘以 `2^k`；低位补 0；注意溢出 |
| 位运算 | 右移 `>>` | 非负整数右移 k 位，相当于整除 `2^k`；低位被丢弃 |
| 位运算 | 负数右移 | 纸面题常按补码算术右移理解；写程序时尽量避免依赖负数位移结果 |
| 位运算 | 判断奇偶 | `(x & 1) == 0` 判断偶数；`(x & 1) == 1` 判断奇数 |
| 位运算 | 取低若干位 | `x & 0xff` 取低 8 位；`x & 15` 取低 4 位 |
| 位运算 | 清除最低位 | `x & ~1` 可以让最低位变成 0 |
| 位运算 | 设置最低位 | `x | 1` 可以让最低位变成 1 |
| 位运算 | 翻转最低位 | `x ^ 1` 可以让最低位 0/1 互换 |
| 位运算 | 小于等于 a 的最大 4 的倍数 | `a & (~3)`；本质是清除最后两位 |
| 位运算 | 异或交换 | `a=a^b; b=a^b; a=a^b;`；前提是两个变量不能是同一块内存 |
| 位运算 | 位运算优先级 | `&`、`^`、按位或优先级不同；复杂表达式必须加括号 |
| 位运算 | 位运算与逻辑运算区别 | `&` 逐位运算，`&&` 判断真假；按位或和逻辑或也不能混用 |
| 算法与描述 | 算法概念 | 有限性、确定性、可执行性、输入、输出；能判断一个描述是否是算法 |
| 算法与描述 | 枚举法 | 把所有可能情况逐一尝试；适合数据范围小、条件明确的问题 |
| 算法与描述 | 单层枚举 | 枚举 `1~n`、枚举数组下标、枚举某个答案候选值 |
| 算法与描述 | 嵌套枚举 | 鸡兔同笼、百钱百鸡、三位数各位关系、两数/三数组合 |
| 算法与描述 | 枚举边界 | 起点、终点、是否包含端点；是否允许重复；是否允许相等 |
| 算法与描述 | 模拟法 | 按题意一步一步更新状态；适合过程类、规则类、回合类题目 |
| 算法与描述 | 过程模拟 | 小球反弹、分鱼、日期推进、数组清零、字符串加密 |
| 算法与描述 | 自然语言描述 | 用文字描述算法步骤；要求步骤清楚、顺序明确、边界完整 |
| 算法与描述 | 流程图描述 | 起止框、输入输出框、处理框、判断框、流程线；从流程图推输出 |
| 算法与描述 | 伪代码描述 | 不依赖具体语言，但结构接近程序；能把伪代码翻译成 C++ |
| 算法与描述 | 复杂度粗略认识 | 枚举次数、循环层数、数据范围是否能承受；不要求严格证明但要有规模意识 |
| 数据结构 | 一维数组定义 | `int arr[5];`、`int arr[] = {1,2,3};`；数组大小在定义时确定 |
| 数据结构 | 数组下标 | C++ 数组下标从 0 开始；长度为 n 的数组合法下标是 `0 ~ n-1` |
| 数据结构 | 数组初始化 | `int arr[5] = {1,2,3};` 后面未给出的元素自动补 0；未初始化局部数组值不确定 |
| 数据结构 | 数组赋值 | 不能整体赋值给数组名；可以逐个元素赋值，如 `arr[i] = x` |
| 数据结构 | 数组连续存储 | 数组元素在内存中连续；可根据元素个数和类型大小计算占用字节数 |
| 数据结构 | `sizeof` 计算数组长度 | `sizeof(arr) / sizeof(arr[0])`；注意传入函数后数组会退化为指针 |
| 数据结构 | 数组遍历 | `for(int i=0; i<n; i++)`；输入、输出、统计、修改每个元素 |
| 数据结构 | 数组求和 | `sum += arr[i]`；注意初值必须正确 |
| 数据结构 | 数组计数 | 统计大于某值、能整除、满足条件的元素个数 |
| 数据结构 | 数组最大值 | `maxVal = arr[0]`，从 `i=1` 开始更新；也可维护最大值下标 |
| 数据结构 | 数组最小值 | `minVal = arr[0]`，避免用 0 当初值导致错误 |
| 数据结构 | 数组交换 | 使用临时变量交换；或理解异或交换；注意下标是否越界 |
| 数据结构 | 数组反转 | 左右指针交换 `arr[l]` 和 `arr[r]`；`l++，r--` |

| 数据结构 | 数组清零 | 循环赋 0、`memset` 基础认识；题目常要求按区间清零 |
| 数据结构 | 数组越界 | `arr[n]` 非法；越界不一定编译报错，可能运行出奇怪结果 |
| 字符串及其函数 | `string` 定义 | `string s="GESP";`、`string s("GESP")`、`string s{"GESP"}` |
| 字符串及其函数 | `string` 下标访问 | `s[0]` 是第一个字符；最后一个字符是 `s[s.length()-1]` |
| 字符串及其函数 | 字符串长度 | `s.length()` / `s.size()` 返回字符序列的字节长度；中文可能占多个字节 |
| 字符串及其函数 | 字符串比较 | `string` 可以用 `==` 比较内容；字符数组不能直接用 `==` 比较内容 |

| 字符串及其函数 | `strlen` 与 `sizeof` | `strlen` 统计 `\0` 之前的字符数；`sizeof` 统计数组占用字节数 |
| 字符串及其函数 | `\0` 与 `'0'` | `\0` 是字符串结束标记，值为 0；`'0'` 是字符 0，ASCII 值为 48 |
| 字符串及其函数 | 大小写转换 | `toupper()`、`tolower()`；也可用 `'A'-'a'` 的差值手动转换 |
| 字符串及其函数 | 字符判断 | 数字字符、大写字母、小写字母判断；常配合循环扫描字符串 |

| 字符串及其函数 | 子串 `substr` | `s.substr(pos, len)` 从下标 `pos` 开始取 `len` 个字符 |
| 字符串及其函数 | 替换 `replace` | `s.replace(pos, len, t)` 从 `pos` 开始删掉 `len` 个字符再插入 `t` |
| 字符串及其函数 | 插入与删除 | `insert`、`erase` 基础认识；常见于字符串模拟题 |
| 字符串及其函数 | 字符串分割 | 按空格、标点或数字/非数字边界分割；电话号码提取、单词计数 |
| 字符串及其函数 | 字符串加密 | 每个字符 ASCII 变化；超过 `'z'` 后回到 `'a'`；注意先判断再修改 |
| 字符串及其函数 | 回文字符串 | 左右指针判断 `s[l] == s[r]`；二进制回文串也可先转字符串再判断 |
| 字符串及其函数 | 左右指针法 | `left` 从左往右，`right` 从右往左；用于反转、分区、回文判断 |
| C++ 语言细节补充 | 函数定义 | 返回类型、函数名、参数列表、函数体；`void` 函数和有返回值函数区分 |
| C++ 语言细节补充 | 函数返回值 | `return` 只能直接返回一个值；多个结果可通过数组、引用、结构体等间接返回 |
| C++ 语言细节补充 | 变量作用域 | 局部变量、全局变量、for 循环变量；内层同名变量会遮蔽外层变量 |
| C++ 语言细节补充 | 自增自减顺序 | `i++` 先用后加，`++i` 先加后用；复杂表达式不要依赖未定义行为 |

| C++ 语言细节补充 | 枚举类型 `enum` | 枚举值默认从 0 开始；底层为整型；不应理解成字符串 |

## 五、错题归因建议

学生错题可以优先按以下方式归类：

1. **编码与进制理解错误**
   - 原码、反码、补码规则混淆
   - 补码表示范围背错
   - 负数补码转真值步骤错误
   - 二进制、八进制、十六进制权值展开错误
   - 小数进制转换不会处理小数点后权值

2. **位运算理解错误**
   - `&` / `&&` 混淆
   - 按位或 / 逻辑或混淆
   - `~` 的补码意义不清
   - 左移右移只机械理解为乘除 2
   - 位运算优先级不加括号
   - 设置、清除、翻转某一位不会迁移

3. **枚举与模拟错误**
   - 枚举起点、终点、是否包含端点错误
   - 嵌套枚举变量含义混乱
   - 没有根据数据范围判断能不能枚举
   - 模拟题状态更新顺序错误
   - 漏掉最后一次输出或最后一次处理

4. **流程图与伪代码阅读错误**
   - 判断框 YES / NO 方向看错
   - 循环回边看漏
   - 处理框执行顺序错
   - 把自然语言条件翻译成 C++ 时漏边界

5. **一维数组错误**
   - 下标从 1 开始写，导致漏掉 `arr[0]`
   - 访问 `arr[n]` 越界
   - 未初始化数组直接使用
   - 最大值、最小值初值设置不合理
   - `sizeof` 结果是字节数，不是元素个数

6. **字符串与字符数组错误**
   - `string` 和 `char[]` 混用规则不清
   - `strlen` 与 `sizeof` 混淆
   - `\0` 和 `'0'` 混淆
   - `substr`、`find`、`replace` 参数含义错误
   - 字符串下标越界
   - 中文字符串长度按字节而不是按肉眼字符数统计

7. **C++ 语言细节错误**
   - 变量作用域不清
   - 内层变量遮蔽外层变量
   - `i++` 和 `++i` 混乱
   - 函数返回类型和 `return` 不匹配
   - 宏定义缺少括号导致表达式错误
