# GESP 八级知识对照表

> 适用场景：题库标签、课后总结、错题归因、阶段测评分析。  
> 整理原则：按照 GESP 八级思维导图知识范围，结合近年 C++ 八级真题常见落地题型进行拆分。  
> 使用说明：一级目录尽量对应思维导图主干；二级目录用于题库标签；三级训练点用于描述学生实际错误和典型考法。

## 一、知识点总表

| 一级目录 | 二级目录 | 三级训练点 / 典型考法 |
|---|---|---|
| 计数原理 | 加法原理 | 分类讨论且各类互斥时相加；交通方案多选一、不同类别物品任选一种、分情况排座位 |
| 计数原理 | 乘法原理 | 分步骤完成一件事时相乘；车牌、取件码、菜品搭配、多个位置依次选择 |
| 计数原理 | 分类与分步判断 | 先判断是“从几类中选一种”还是“连续完成几步”；加法和乘法经常混合出现 |
| 计数原理 | 补集计数 | 至少一个、不能全部相同、不能排第一、至少包含某类时，可用总数减去不合法情况 |
| 计数原理 | 容斥初步 | 两个限制同时出现时，注意重复扣除；常见于包含某数字、满足多类条件的计数题 |
| 计数原理 | 可重复与不可重复 | 题目说“可以重复使用”与“无重复数字”完全不同；每一步的可选数量会变化 |
| 计数原理 | 有序与无序 | 角色不同、位置不同、先后顺序不同通常是有序；只选出一组人或物通常是无序 |
| 计数原理 | 边界限制 | 数字 0 能否放首位、字母是否排除 I/O、座位是否有主座、物品是否相同都要单独判断 |
| 计数原理 | 概率中的计数 | 用有利情况数除以总情况数；生男生女、随机点覆盖、等可能事件常用计数转概率 |
| 计数原理 | 程序枚举验证 | 小范围计数可写循环验证，但选择题中要会手推循环范围和合法条件 |
| 排列与组合 | 排列概念 | 从 n 个不同元素中取 m 个并考虑顺序；队长副队长、排队、座位安排、照片顺序等 |
| 排列与组合 | 组合概念 | 从 n 个不同元素中取 m 个不考虑顺序；宣传委员、选书、选小组、选四张照片组合 |
| 排列与组合 | 阶乘与全排列 | n 个不同对象全排列为 n!；递归全排列输出个数也应对应阶乘 |
| 排列与组合 | 相邻捆绑法 | 要求两人相邻或一家人相邻时，把整体当作一个块，再乘块内部排列 |
| 排列与组合 | 不相邻插空法 | 男生女生不相邻、某类对象不能相邻时，先排一类，再在空位中插入另一类 |
| 排列与组合 | 至少与至多 | 至少 1 个、至多 1 个、恰好 2 个分别对应补集、分类和直接组合 |
| 排列与组合 | 相同元素排列 | 相同红球、绿球、黄球排列要用多重排列，总排列除以重复元素阶乘 |
| 排列与组合 | 分组后再排列 | 先分组、再确定组内/组间顺序；注意“两组无区别”和“组内两人无顺序”的区别 |
| 排列与组合 | 圆桌与座位 | 若每个座位被认为不同，则按普通座位排列；若旋转等价，才需要除以 n |
| 排列与组合 | 二进制状态表示组合 | 整数二进制某位为 1 表示选中；常考位运算、下一个组合、状态枚举 |
| 排列与组合 | 递归生成排列 | 交换当前位置与后续元素，递归下一位，回溯时换回来；边界为 begin == end |
| 排列与组合 | 递归生成组合 | 选或不选、choose(n,m) 递归、组合数递推；注意重复子问题可用记忆化 |
| 排列与组合 | 排列组合与复杂度 | 全排列通常 O(n!)，组合枚举通常与 C(n,m) 有关；选择题常考增长速度 |
| 杨辉三角 | 杨辉三角定义 | 两侧为 1，中间每个数等于上一行左上与右上的和；常用于组合数和路径计数 |
| 杨辉三角 | 数组实现 | 常用二维数组 a[i][j]；边界 j == 1 或 j == i 置 1，中间递推 |
| 杨辉三角 | 下标体系 | 从第 0 行还是第 1 行开始会影响答案；第 n 行行和通常为 2^n |
| 杨辉三角 | 组合数对应 | 杨辉三角第 n 行第 k 项对应组合数；二项式系数和 C(n,k) 联系紧密 |
| 杨辉三角 | 二项式展开 | (x+y)^n、(ax-y)^n 中指定项系数；注意符号、幂次和组合数 |
| 杨辉三角 | 路径计数 | 只能向右/向上或向下/向右走的网格路径数，本质常与组合数或杨辉递推一致 |
| 杨辉三角 | choose 递归 | C(n,m)=C(n-1,m-1)+C(n-1,m)；朴素递归会重复计算，记忆化后降为状态数 |
| 杨辉三角 | 记忆化搜索 | 用 record_choose 记录已算结果；注意 0 作为未计算标记时，边界值要先返回 |
| 杨辉三角 | 输出与格式 | 输出三角形时每行列数不同；循环范围通常为 j <= i |
| 杨辉三角 | 溢出风险 | 组合数增长很快；根据题目范围选择 int、long long 或高精度 |
| 倍增法 | 倍增概念 | 每次把规模扩大或缩小一倍；用于快速定位范围、快速幂、二进制拆分 |
| 倍增法 | 二进制拆分 | 把指数、步长、状态拆成若干二进制位；每一位只处理一次 |
| 倍增法 | 快速幂迭代 | 当指数当前位为 1 时乘入答案；底数每轮平方，指数右移一位 |
| 倍增法 | 快速幂递归 | 把 n 次幂转化为 n/2 次幂；偶数平方，奇数再乘一次底数 |
| 倍增法 | 快速幂复杂度 | 指数每次减半，时间复杂度 O(log n)，空间复杂度看递归或迭代实现 |
| 倍增法 | 模运算结合 | 乘法后立即取模；避免中间结果过大，必要时使用 long long |
| 倍增法 | 倍增搜索范围 | 未知边界时先 1、2、4、8 扩大范围，再在范围内二分或定位 |
| 倍增法 | 二进制位运算 | 右移、按位与、最低位 1、清除某一位等，常和组合状态题结合 |
| 倍增法 | 低位连续 1 处理 | 用类似 (c-1) 异或 c 找到低位变化区域；组合下一个状态题常考 |
| 倍增法 | 边界条件 | 指数为 0 返回 1；模数、负数、溢出、递归终止条件都要单独处理 |
| 代数与平面几何 | 一元一次方程 | 把实际问题转成 ax+b=c；注意整数解、范围限制和枚举验证 |
| 代数与平面几何 | 二元一次方程 | 两个未知量满足线性关系；常与枚举、计数、非负整数解结合 |
| 代数与平面几何 | 一元二次方程 | 用判别式判断实根；例如 x^2+ax+b=0 有实根需 a*a-4*b >= 0 |
| 代数与平面几何 | 数列求和公式 | 等差数列、等比数列、平方和、立方和可替代暴力循环，是算法优化常用工具 |
| 代数与平面几何 | 坐标与斜率 | 斜率为 y 的差除以 x 的差；竖直线斜率不存在，不能直接除以 0 |
| 代数与平面几何 | 两点距离 | 欧氏距离为 sqrt(dx*dx+dy*dy)；C++ 中 ^ 不是乘方 |
| 代数与平面几何 | 三点共线 | 用叉积判断共线：两个向量叉积绝对值小于 eps；避免直接比较斜率 |
| 代数与平面几何 | 三角形面积 | 已知两边及夹角面积为 a*b*sin(theta)/2；坐标面积可用叉积 |
| 代数与平面几何 | 余弦定理 | 已知两边及夹角，第三边为 sqrt(a*a+b*b-2*a*b*cos(theta)) |
| 代数与平面几何 | 圆与扇形 | 扇形面积为 r*r*theta/2；弓形面积常为扇形面积减三角形面积 |
| 代数与平面几何 | 弦长 | 圆心角为 theta 时弦长为 2*r*sin(theta/2) |
| 代数与平面几何 | 长方形与网格 | 长方形面积、网格边权、水平边和垂直边数组下标要分清 |
| 代数与平面几何 | 浮点误差 | double 不能直接用 == 判断几何关系；通常使用 fabs(x) < 1e-8 |
| 代数与平面几何 | 三角函数单位 | sin、cos 使用弧度而不是角度；题目若给圆心角通常明确为弧度 |
| 图论算法及综合应用 | 图基本概念 | 顶点、边、入边、出边、有向图、无向图、带权图、连通性、强连通与弱连通 |
| 图论算法及综合应用 | 邻接矩阵 | n 个顶点矩阵大小为 n*n；无边常用 INF 或 0 表示，需结合题意判断 |
| 图论算法及综合应用 | 邻接表 | 有向图出边表边节点数为 e；无向图邻接表通常存 2e 个边节点 |
| 图论算法及综合应用 | 树与生成树 | 连通无向图存在生成树；n 个顶点生成树有 n-1 条边；有环图可能有多棵生成树 |
| 图论算法及综合应用 | 二叉树基础 | 遍历、释放节点、广度优先搜索都通常访问每个节点一次，复杂度 O(n) |
| 图论算法及综合应用 | 二叉搜索树 | 中序遍历有序；查找最好 O(1) 或 O(log n)，最差可退化为 O(n) |
| 图论算法及综合应用 | 平衡二叉树 | 树高与 log n 相关；但具体高度受定义和节点数范围影响 |
| 图论算法及综合应用 | BFS 图遍历 | 用队列逐层访问；邻接表复杂度 O(V+E)，邻接矩阵复杂度 O(V^2) |
| 图论算法及综合应用 | DFS 图遍历 | 用递归或栈访问；注意 visited 防止重复访问和死循环 |
| 图论算法及综合应用 | 最小生成树概念 | 只适用于连通无向带权图；目标是连通所有点且总权值最小 |
| 图论算法及综合应用 | Kruskal 算法 | 按边权从小到大排序；用并查集判断是否成环，不同集合才合并 |
| 图论算法及综合应用 | Prim 算法 | 从一个点开始维护到生成树集合的最小边；常用 key、parent、inMST 数组 |
| 图论算法及综合应用 | 并查集 | find 找代表元，union 合并集合；路径压缩可优化 Kruskal |
| 图论算法及综合应用 | 最短路径概念 | 单源最短路、任意两点最短路、负权边、负权环要区分 |
| 图论算法及综合应用 | Dijkstra 算法 | 适用于非负边权；每次选当前未确定的最近点并松弛邻边 |
| 图论算法及综合应用 | Dijkstra 堆优化 | 邻接表加优先队列常见复杂度 O((V+E)log V)；适合稀疏图 |

| 图论算法及综合应用 | 简单路径边数 | n 个顶点的简单路径最多包含 n-1 条边；否则重复顶点形成环 |
| 图论算法及综合应用 | 网格最短路与 DP | 只能向固定方向移动时常用动态规划；允许四方向且求最短步数时常用 BFS |
| 图论算法及综合应用 | 算法选型 | 稀疏图优先邻接表，稠密图可用邻接矩阵；单源选 Dijkstra，多源选 Floyd |
| 图论算法及综合应用 | 图论综合读图 | 根据代码中的 Edge、next、first、graph[u][v] 还原有向边或无向边 |
| 算法时间和空间效率分析 | 复杂度基本概念 | 时间复杂度描述随输入规模增长的趋势；忽略常数但不能忽略主变量 |
| 算法时间和空间效率分析 | 空间复杂度 | 关注额外数组、递归栈、队列、邻接表边节点、DP 表等额外空间 |
| 算法时间和空间效率分析 | 常数复杂度 | 固定次数操作、数组一次访问、简单赋值通常为 O(1) |
| 算法时间和空间效率分析 | 线性复杂度 | 单次遍历数组、释放 n 个树节点、BFS 访问 n 个树节点通常为 O(n) |

| 算法时间和空间效率分析 | 平方根复杂度 | 循环条件 j*j <= i 或枚举因子到平方根，常见 O(sqrt n) 或累加后更高 |
| 算法时间和空间效率分析 | 线性对数复杂度 | 归并排序、堆优化相关操作、排序后处理通常出现 O(n log n) |
| 算法时间和空间效率分析 | 平方复杂度 | 两层完整循环、邻接矩阵扫描、朴素 Dijkstra 常见 O(n^2) 或 O(V^2) |
| 算法时间和空间效率分析 | 立方复杂度 | 三重完整循环、Floyd、三维 DP 常见 O(n^3) 或 O(V^3) |
| 算法时间和空间效率分析 | 指数与阶乘复杂度 | 朴素斐波那契、全排列、枚举子集增长很快；要能估计不可承受范围 |

| 算法时间和空间效率分析 | 排序复杂度 | 归并排序稳定 O(n log n)；快速排序平均 O(n log n)，最坏 O(n^2) |
| 算法时间和空间效率分析 | 查找复杂度 | 顺序查找 O(n)，二分查找 O(log n)，BST 最差可能 O(n) |
| 算法时间和空间效率分析 | 树图遍历复杂度 | 邻接表 DFS/BFS 为 O(V+E)；邻接矩阵遍历邻边常为 O(V^2) |
| 算法时间和空间效率分析 | 动态规划复杂度 | 通常等于状态数乘每个状态转移数；LCS 为 O(nm)，LIS 朴素为 O(n^2) |
| 算法时间和空间效率分析 | 最短路复杂度 | 朴素 Dijkstra O(V^2)，堆优化 O((V+E)log V)，Floyd O(V^3) |
| 算法时间和空间效率分析 | 最小生成树复杂度 | Kruskal 主要来自边排序 O(E log E)；朴素 Prim 常见 O(V^2) |

| 算法时间和空间效率分析 | 变量规模区分 | O(n*m)、O(V+E)、O(n log m) 不能随意写成只含 n 的形式 |
| 算法优化 | 差异分析 | 同一问题可用枚举、数学公式、DP、贪心、图论建模；要比较正确性和复杂度 |

| 算法优化 | 暴力到二分 | 答案具有单调性时，可以从线性枚举答案优化为二分答案 |

## 五、错题归因建议

学生错题可以优先按以下方式归类：

1. **计数与排列组合错误**
   - 加法原理和乘法原理混用，不会判断分类还是分步
   - 有序和无序不区分，导致排列组合选错
   - 至少、至多、恰好、不能、必须相邻等限制没有单独建模
   - 相同元素、圆桌、主座、座位不同等边界没有读清
   - 概率题不会先转化为总情况数和有利情况数

2. **杨辉三角与二项式错误**
   - 下标从 0 还是从 1 开始混乱
   - 只会背杨辉三角，不会连接组合数、二项式系数和路径计数
   - 递推边界没有处理好，数组越界或边界不是 1
   - 朴素 choose 递归复杂度估算错误，不理解重复子问题

3. **倍增与位运算错误**
   - 快速幂的指数位处理、底数平方、取模顺序混乱
   - 二进制状态中元素编号和位编号对应不清
   - 最低位 1、清除位、右移左移等位运算不会手推
   - 指数为 0、模数、溢出等边界漏掉

4. **代数与几何建模错误**
   - 不会把题目转成方程、公式或坐标表达式
   - 斜率、距离、共线、面积公式混淆
   - 把 C++ 的 ^ 当作乘方使用
   - double 精度误差没有用 eps 处理
   - 三角函数弧度制、扇形面积、弦长公式记忆不牢

5. **图论算法错误**
   - 图的存储方式不清楚，邻接矩阵和邻接表边数、空间复杂度混淆
   - 连通图、强连通、弱连通、生成树、最小生成树概念混淆
   - Kruskal 不会用并查集判断是否成环
   - Prim 更新条件缺少是否在树内、是否存在边、是否更小三个判断
   - Dijkstra 和 Floyd 的适用场景、复杂度、负权条件混乱
   - 松弛操作不会写，INF 判断和 dist 更新顺序错误

6. **复杂度分析错误**
   - 只数循环层数，不看循环变量变化方式和真实边界
   - 对 O(log n)、O(sqrt n)、O(n log n)、O(V+E)、O(V^3) 不敏感
   - 不会分析递归分支数、递归深度和记忆化后的状态数
   - 忽略空间复杂度中的 DP 表、图存储、递归栈和队列
   - 最好、最坏、平均复杂度混为一谈

7. **算法优化错误**
   - 不会比较暴力、公式、DP、贪心、图论建模之间的差异
   - 看到题目就套模板，不能说明为什么优化后仍然正确
   - 线性筛、LIS 二分优化、堆优化 Dijkstra 等关键不变量不清
   - 缺少补集、容斥、数列求和、二项式恒等式等数学优化意识
   - 为了快而牺牲边界，导致溢出、越界、漏情况

8. **C++语言与数据结构错误**
   - 类、对象、构造函数、析构函数、继承、虚函数概念只会背结论
   - class 与 struct 默认访问权限记反
   - 二维数组声明、初始化和传参规则掌握不牢
   - 引用、指针、结构体链表式邻接表不会根据代码画图
   - 标准库函数参数和返回值不熟，尤其 sqrt、pow、fabs、strlen、stoi
