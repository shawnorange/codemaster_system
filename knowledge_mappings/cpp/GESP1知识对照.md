| 变量与标识符 | 非关键字易错点 | `cin`、`cout`、`endl`、`printf`、`scanf`、`abs` 不是 C++ 关键字，但不建议做变量名 |
| 数据类型 | 整型 `int` | 整数存储；整数除法；`10 / 4 == 2`；`37 / 4 == 9` |
| 数据类型 | 浮点型 `float / double` | 小数存储；`7.0` 默认是 `double`；小数参与运算会得到小数结果 |
| 数据类型 | 字符型 `char` | `'3'` 是字符；`char(66)`；字符可以参与整数运算 |
| 数据类型 | 布尔型 `bool` | `true`、`false`；输出通常为 `1` 和 `0`；非 0 为真，0 为假 |
| 数据类型 | 字符串字面量 | `"Hello"` 是字符串；双引号内可以有汉字；字符串不能直接乘整数 |
| 数据类型 | 字符与字符串区别 | `'3'` 是字符，`"3"` 是字符串；单引号不能随便替代双引号 |
| 数据类型转换 | 隐式类型转换 | `int + double` 结果偏向小数；`char + int` 会按 ASCII 数值参与运算 |
| 数据类型转换 | 强制类型转换 | `int(3.14)`、`(char)66`、`char(66)`；小数转整数会去掉小数部分 |
| 数据类型转换 | 整数除法转小数 | `a / b` 与 `(a + 0.0) / b` 的区别 |
| 输入输出 | `cin` 输入 | `cin >> a;`；多个变量连续输入；输入 `5+2` 给整型变量通常只读到 `5` |
| 输入输出 | `cout` 输出 | `cout << a << endl;`；连续输出；字符串和表达式分开理解 |
| 输入输出 | `endl` 与换行 | `endl` 表示换行；也可以使用 `'\n'` |
| 输入输出 | `printf` 基础 | `%d` 输出整数；`%f` 输出小数；`%.2f` 保留两位小数；`%%` 输出百分号 |
| 输入输出 | `scanf` 基础 | `%d` 输入整数；`%lf` 输入 `double`；变量前通常要加 `&` |
| 输入输出 | 占位符数量 | `printf` 中占位符和后面的值要匹配；值多了通常多余部分不用，值少了结果不可靠 |
| 输入输出 | 宽度与补零 | `%2d` 按宽度输出；`%02d` 不足两位前面补 0 |
| 输入输出 | 精确输出 | 空格、换行、标点、大小写必须完全符合题目要求 |
| 运算符与表达式 | 算术运算 | `+`、`-`、`*`、`/`、`%`；先乘除取模，后加减 |
| 运算符与表达式 | 取模运算 | `N % 10` 取个位；`N % 2` 判断奇偶；`N % k` 判断余数 |
| 运算符与表达式 | 整除判断 | `a % b == 0`；判断倍数、因数、是否能整除 |
| 运算符与表达式 | 赋值运算 | `=` 是赋值，不是判断相等 |
| 运算符与表达式 | 复合赋值 | `+=`、`-=`、`*=`、`/=`、`%=`；例如 `a *= 3`、`a %= 4` |
| 运算符与表达式 | 自增自减 | `i++`、`++i`；重点理解循环中的变化和 `sum += i++` |
| 运算符与表达式 | 关系运算 | `>`、`<`、`>=`、`<=`、`==`、`!=`；结果为真或假 |
| 运算符与表达式 | 逻辑运算 | `&&`、`||`、`!`；并且、或者、取反 |
| 运算符与表达式 | 逻辑表达式结果 | C++ 中真常作为 `1`，假常作为 `0`；如 `(6 > 2) * 2 == 2` |
| 运算符与表达式 | 逗号表达式 | `(3, 2)` 的值是最后一个表达式的值；`a = (b = 3, c = 4, b + c)` |
| 运算符与表达式 | 运算优先级 | 括号优先；`* / %` 高于 `+ -`；关系运算、逻辑运算、赋值运算顺序要小心 |
| 运算符与表达式 | 错误区间写法 | `10 <= N <= 12` 在 C++ 中不是数学区间判断；应写 `N >= 10 && N <= 12` |
| 运算符与表达式 | 链式比较陷阱 | `a < b < c`、`a == b == 0` 容易得到错误结果 |
| 运算符与表达式 | 非幂运算符 | `^` 不是乘方；`a ^ 2` 不能表示 `a` 的平方 |
| 顺序结构 | 从上到下执行 | 语句按顺序执行；后一次赋值会覆盖前一次值 |
| 顺序结构 | 中间变量 | 保存原数、保存临时结果；如 `N0 = N` 防止原数被循环改掉 |
| 顺序结构 | 公式计算 | 购物金额、面积、周长、温度转换、时间差等 |
| 分支结构 | 单分支 `if` | 满足条件才执行；`if(condition) statement;` |
| 分支结构 | 双分支 `if-else` | 二选一；奇偶、够不够钱、是否超过温度限制 |
| 分支结构 | 多分支 `else-if` | 多种情况判断；能被 3 整除、能被 7 整除、都不能 |
| 分支结构 | 分支条件 | 条件可以是 `bool`，也可以是 `int`；0 为假，非 0 为真 |
| 分支结构 | 嵌套分支 | 闰年、月份天数、范围判断；先大类再小类 |
| 分支结构 | `switch-case` | `case`、`break`、`default`；适合固定值分类 |
| 分支结构 | `break` 穿透问题 | `case` 后没有 `break` 会继续执行后面的 `case` |
| 分支结构 | 条件运算符 | `条件 ? 表达式1 : 表达式2`；客观题中可能出现，一级只要求能识读 |
| 循环结构 | `for` 循环基础 | 起点、终点、步长；`i < n` 与 `i <= n` 的区别 |
| 循环结构 | `for` 循环三部分 | 初始化、循环条件、更新语句；有时可以省略某一部分 |
| 循环结构 | 循环结束后的变量 | `for(i = 0; i <= 100; i++)` 结束后 `i` 可能是 101 |
| 循环结构 | `while` 循环 | 先判断再执行；适合不确定循环次数，如数位处理 |
| 循环结构 | `do-while` 循环 | 先执行一次再判断；循环体至少执行一次 |
| 循环结构 | 死循环 | `while(1)`、`while(true)`；需要 `break` 或变量变化退出 |
| 循环结构 | `break` | 直接结束当前循环或 `switch` |
| 循环结构 | `continue` | 跳过本轮后续语句，进入下一轮；在 `for` 中仍会执行更新语句 |
| 循环结构 | 循环计数 | `cnt++`；统计奇数个数、偶数个数、满足条件的数 |
| 循环结构 | 循环求和 | `sum += i`；区间求和、幸运数求和、各位数字和 |
| 循环结构 | 循环求积 | 阶乘、连续乘法；一级低频，但可作为拓展 |
| 循环结构 | 条件跳过 | 跳过某个数的倍数；`if(i % m != 0) cout << i;` |
| 循环结构 | 输入多组数据 | 先输入 `n`，再循环输入 `n` 个数；或输入到 0 结束 |
| 简单枚举 | 区间枚举 | 从 `L` 到 `R` 枚举每个数，判断是否满足条件 |
| 简单枚举 | 因数枚举 | 从 `1` 到 `n`，判断 `n % i == 0` |
| 简单枚举 | 质数判断 | 统计因数个数是否为 2；或从 `2` 到 `N-1` 找因数 |
| 简单枚举 | 完全平方数 | 枚举 `i` 判断 `i * i == N` |
| 简单枚举 | 立方数 | 枚举 `i` 判断 `i * i * i == N` |
| 简单枚举 | 长方形种数 | 枚举宽 `w`，用 `area % w == 0` 判断；可用 `w * w <= area` 去重 |
| 简单枚举 | 跳过倍数 | 报数时跳过 `m` 的倍数；输出所有非倍数 |
| 数学判断 | 奇偶判断 | `x % 2 == 0` 是偶数；`x % 2 != 0` 是奇数 |
| 数学判断 | 倍数判断 | `x % k == 0`；例如 9 的倍数、7 的倍数 |
| 数学判断 | 余数判断 | `x % 7 == 2`；用于筛选满足指定余数的数 |
| 数学判断 | 大小比较 | 超预算、温度过高、开始时间早于结束时间 |
| 数学判断 | 闰年判断 | `y % 400 == 0` 或 `y % 4 == 0 && y % 100 != 0` |
| 数学判断 | 四舍五入到整十 | `(x + 5) / 10 * 10` |
| 数学应用 | 购物问题 | 总价计算、预算够不够、剩余或缺少多少钱 |
| 数学应用 | 购买数量 | `money / price` 买几本；`money % price` 剩多少钱 |
| 数学应用 | 相同数量购买 | 两种商品各买相同数量：`n / (a + b)` |
| 数学应用 | 时间差 | 转成分钟或秒后相减 |
| 数学应用 | 时间进位 | 秒转时分秒；分钟转小时分钟；小时跨天 |
| 数学应用 | 星期周期 | `(x - 1 + n % 7) % 7 + 1`；注意星期日用 0 还是 7 |
| 数学应用 | 月份天数 | 大月、小月、2 月结合闰年 |
| 数位处理 | 取个位 | `N % 10` |
| 数位处理 | 去个位 | `N / 10` 或 `N /= 10` |
| 数位处理 | 取十位 / 百位 | `N / 10 % 10`、`N / 100 % 10` |
| 数位处理 | 位数统计 | `while(N){ cnt++; N /= 10; }` |
| 数位处理 | 数位和 | 循环取个位累加 |
| 数位处理 | 各位平方和 | `sum += (N % 10) * (N % 10)` |
| 数位处理 | 个位条件 | 个位为某数字：`N % 10 == k` |
| 数位处理 | 原数保护 | 数位循环会改变 `N`，需要时先保存 `N0 = N` |
| 字符与 ASCII | 字符常量 | `'A'`、`'0'`、`'3'`；单引号表示字符 |
| 字符与 ASCII | 字符转整数 | `int(ch)`；`char(66)`；字符本质上可按编码参与运算 |
| 字符与 ASCII | 数字字符 | `'0'` 到 `'9'`；数字字符转数字：`ch - '0'` |
| 字符与 ASCII | 字符比较 | `ch >= 'A' && ch <= 'Z'`；字符可以比较大小 |
| 字符与 ASCII | 字符分组 | `switch(c)` 或 `if` 判断不同字符属于哪一组 |
| 客观题低频识读 | 简单数组识读 | `int arr[] = {...};`；下标从 0 开始；会读简单 `for` 输出 |
| 客观题低频识读 | 简单三目表达式 | `condition ? a : b`；识别条件真假和最终赋值 |
| 客观题低频识读 | 简单函数调用 | `int()`、`char()`、`printf()`、`scanf()`、`cout`、`cin` |
| 输出格式 | 不多不少 | 不多输出提示语，不少输出换行 |
| 输出格式 | 空格控制 | 数字之间是否有空格；最后是否换行 |
| 输出格式 | 多行输出 | 每行一个结果；如所有因数、四舍五入结果 |
| 输出格式 | 文字输出 | `Yes/No`、`Temperature is too high!`、中文提示文本必须完全一致 |
| 输出格式 | 小数格式 | 保留两位小数：`printf("%.2f", x)` |
| 输出格式 | 字符串与表达式 | `"a+1="` 原样输出，`a+1` 才计算 |

## 五、错题归因建议

学生错题可以优先按以下方式归类：

1. **计算机基础概念错误**
   - 输入设备和输出设备混淆
   - 内存、外存、存储设备混淆
   - 操作系统、应用软件、开发环境混淆
   - 高级语言、源程序、可执行程序、编译运行概念不清

2. **变量与类型错误**
   - 变量没有定义就使用
   - 标识符中出现空格、减号、特殊符号
   - 把 `cin`、`cout`、`printf` 当作关键字
   - `int`、`double`、`char`、`bool` 的结果类型判断错误
   - 字符和字符串混淆

3. **输入输出错误**
   - `cin` 输入表达式时误以为会自动计算
   - `scanf` 忘记 `&`
   - `printf` 占位符写错
   - `%d`、`%f`、`%lf`、`%.2f` 混淆
   - 输出格式多空格、少换行、多提示语

4. **表达式理解错误**
   - 整数除法
   - 取模
   - 赋值和相等判断
   - 逻辑运算
   - 逗号表达式
   - 运算优先级
   - `^` 不是乘方
   - 链式比较写法错误

5. **分支结构错误**
   - `if` 条件真假判断错误
   - `if-else` 漏情况
   - `else-if` 顺序不清
   - `switch-case` 忘记 `break`
   - 把 `N % 2` 当成“偶数条件”

6. **循环结构错误**
   - `i < n` 和 `i <= n` 边界错误
   - 循环结束后变量值判断错误
   - `i++` 出现多次导致跳数
   - `continue` 误以为结束整个循环
   - `break` 和 `continue` 作用混淆
   - `while` 条件不变化导致死循环

7. **简单枚举错误**
   - 因数枚举漏掉 `n` 本身
   - 质数判断把 1 当成质数
   - 完全平方数、立方数枚举边界错误
   - 区间 `[L, R]` 是否包含端点没看清
   - 跳过倍数时条件写反

8. **数位处理错误**
   - `N % 10` 和 `N / 10` 混淆
   - 取十位、百位公式写错
   - 循环后原数被改成 0
   - 位数统计没有考虑输入范围
   - 个位判断和倍数判断条件混淆

9. **数学应用错误**
   - 买书问题中商和余数写反
   - 时间问题没有统一成分钟或秒
   - 星期周期没有处理 0 和 7
   - 闰年条件不完整
   - 四舍五入到整十没有使用 `(x + 5) / 10 * 10`

10. **考试习惯错误**
    - 题目问“正确的是”还是“错误的是”没看清
    - 样例解释没有转化成代码条件
    - 程序阅读不手推变量表
    - 输出格式没有逐字符检查
    - 只记语法，不会把语法落到题意中
