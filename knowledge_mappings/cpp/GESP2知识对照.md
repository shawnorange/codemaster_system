## 五、错题归因建议

学生错题可以优先按以下方式归类：

1. **语法型错误**
   - 变量命名错误
   - 关键字误用
   - 少分号、括号不匹配
   - `=` 和 `==` 混淆

2. **表达式理解错误**
   - 整数除法
   - 取模
   - 逻辑表达式
   - 逗号表达式
   - 运算优先级

3. **流程控制错误**
   - `if-else` 分支漏情况
   - `break` / `continue` 作用范围错误
   - 循环起止边界错误
   - 死循环风险

4. **枚举边界错误**
   - `j = 1`
   - `j = i`
   - `j = i + 1`
   - 是否允许重复
   - 是否允许相等

5. **数位处理错误**
   - 取个位
   - 去个位
   - 取某一位
   - 数位和
   - 逆序
   - 原数被循环改成 0

6. **输出格式错误**
   - 多空格
   - 少换行
   - 多提示语
   - 字符画行列数错误
